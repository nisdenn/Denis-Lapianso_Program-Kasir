# Program Kasir

Aplikasi Program Kasir yang ditulis dalam Python. Terdapat dua versi dalam proyek ini: versi CLI dan versi GUI.

## Fitur Utama

- Mencatat pesanan dan transaksi.
- Menghitung total belanja.
- Antarmuka GUI untuk kemudahan penggunaan (Kasir_Gui.py).
- Antarmuka CLI untuk sistem terminal (ProgramKasir.py).

## Cara Penggunaan

Pastikan Python sudah terinstal di sistem Anda.

### Menjalankan versi GUI
```bash
python src/Kasir_Gui.py
```

### Menjalankan versi CLI
```bash
python src/ProgramKasir.py
```

## Struktur Direktori

- `src/` : Berisi kode sumber utama program kasir.
